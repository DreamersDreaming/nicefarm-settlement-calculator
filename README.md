# 1개월 추가 급전 비용 계산기 (NiceFarm)

1금융권·농신보 한도가 다 찼을 때, 거래 이력 기반으로 추가로 쓸 수 있는
1개월 단기 급전(1~3억)의 실이자 비용과 추가 납품 손익분기 마진을 계산하는 단일 HTML 페이지입니다.

- 입력: 필요 금액(5천만·1억·2억·3억) · 사용 기간(30·35·50·60일) · 현재 한도 상태
- 기준: 연 11.0%(2금융 단기 여신) · 실이자율 = 11.0% × 사용일수 / 365
- 파일: `index.html` (외부 의존성 없는 단일 파일)
- GitHub Pages: `main` 브랜치 루트(`/`)
